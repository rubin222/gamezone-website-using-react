# GameZone
GameZone is a gaming discovery website built with React and JavaScript. The project focuses on
creating a clean and responsive  interface where users can explore the games.

## Technologies
- React
- JavaScript
- Vite
- HTML5
- CSS
- React Router
- Lucide React

## Planned Features
- Gaming homepage
- Game details
- Responsive Layout

## Installation
- Clone the repository: git clone https://github.com/rubin222/gamezone-website-using-react.git
- Move into the project directory: cd gamezone
- Install dependencies: npm install
- Start the development server: npm run dev
